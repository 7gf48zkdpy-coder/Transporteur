# Transporteur VTC

Application de réservation de chauffeur privé : espace clients (`index.html`) et espace chauffeur (`chauffeur.html`).

- Site statique (HTML, CSS, JavaScript), sans framework.
- Base de données : Supabase (voir `supabase/README.md`).
- Hébergement : Netlify, mis à jour automatiquement à chaque modification de ce dépôt.
- Les icônes PNG sont créées à la mise en ligne par `build-icons.js` (voir `netlify.toml`).
