# Transporteur — ce qu'il faut savoir

- **Lien clients** : l'adresse Netlify du site (ex. `https://transporteur-vtc.netlify.app`)
- **Espace chauffeur** : la même adresse + `/chauffeur.html`
- Connexion chauffeur : votre e-mail + votre mot de passe (modifiable dans Réglages).

## Installer sur l'iPhone
Ouvrez le lien dans **Safari** → bouton **Partager** → **Sur l'écran d'accueil** → **Ajouter**.
Faites-le une fois pour l'espace chauffeur (icône « Chauffeur »), et une fois pour le lien clients si vous voulez tester.

## Bon à savoir
- **GPS** : votre position est envoyée tant que l'espace chauffeur est ouvert et l'écran allumé.
- **Nouvelle demande** : bip + vibration quand l'espace chauffeur est ouvert.
- **Comptes clients** : chaque client est reconnu sur son téléphone. S'il change de téléphone, il recrée son compte en 10 secondes.
- **Carte et itinéraires** : services gratuits OpenStreetMap (OpenFreeMap, Photon, OSRM).
- **Hébergement** : Netlify. **Base de données** : Supabase (voir `supabase/README.md`).
